# Pug Android SDK

Native Kotlin SDK for [Pug](https://pug.sh) analytics on Android: event tracking, identity,
sessions, consent, and batched delivery.

> **Status: in development.** The `Pug` API works on Android, with stored state, auto-properties,
> app lifecycle, screen and install events. Typed events and a published release are still to
> come. Progress and design decisions are in [PLAN.md](PLAN.md); contributor setup is in
> [docs/development.md](docs/development.md).

Planned coordinates: `sh.pug:pug-android`, `minSdk 21`, with kotlin-stdlib and
kotlinx-coroutines-core as the only runtime dependencies.
